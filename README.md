# katekislitsyna_nastavnichestvo

Лендинг наставничества Кейт Кислицыной: съёмка, Reels и развитие блога.

Статический сайт на HTML, CSS и JavaScript. Сборка и зависимости не нужны.

## Локальный запуск

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080.

## Файлы

- `index.html` — содержание страницы.
- `style.css` — адаптивное оформление.
- `script.js` — появления и плавное наслаивание блоков.
- `kate.jpg` — фотография.

Для публикации разместите файлы в корне любого статического хостинга.
